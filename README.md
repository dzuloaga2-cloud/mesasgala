# Mesas Gala

Organizador de mesas para la Gala de Cuarto Medio. Permite distribuir a las familias de los estudiantes en mesas redondas arrastrando y soltando, y exportar la distribución en PDF y Excel para el centro de eventos.

- Arrastra a una persona para moverla sola, o el nombre del estudiante para mover a toda su familia.
- Importa la lista desde Excel: una fila por estudiante (`Estudiante ; Curso ; Invitado 1 ; Invitado 2 …`).
- El avance se guarda en el navegador; usa "Exportar → Respaldo completo" para continuar en otro equipo.

Aplicación estática (un solo `index.html`), publicada en https://mesasgala.vercel.app
