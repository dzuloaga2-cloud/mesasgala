Importar lista

Una fila por estudiante. Copia las filas desde Excel y pégalas aquí (o separa con punto y coma):
Estudiante ; Invitado 1 ; Invitado 2 ; Invitado 3 …
Si aún no tienes los nombres, pon la cantidad de invitados:
Ana Pérez ; 3 → crea 3 invitados que luego puedes renombrar.
